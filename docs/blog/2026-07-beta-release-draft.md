ビットバンクは、AIエージェントを通じた新しい取引体験の実現に向けた実証実験として、暗号資産取引所「bitbank」のデータや機能を AI から利用できる **MCPサーバ** と **CLI** のベータ版を、OSS として公開しました（[プレスリリース](https://bitbank.cc/announcement/20260710_01/)）。

この記事では、実際にそれらのツールを Claude Desktop やコーディングエージェントと連携し、AI を活用した相場分析や資産状況の可視化などの始め方を紹介します。あなたの AI クライアントを bitbank につないで、いろいろなことをやってみましょう。読み終わる頃には、次の 3 つがわかります。

1. **何ができるのか** — 冒頭の動画がその答えです。市場分析からポートフォリオ確認、注文操作まで、AI に話しかけるだけで動きます
2. **MCP と CLI、どちらを使えばいいのか** — 2 つのツールの使い分け
3. **5 分で試す手順** — どちらも `npx` / `npm` だけで動きます。インストール作業はほぼありません

## 2. どちらを使えばいい？ — MCP と CLI の使い分け

2 つのツールは、**同じ bitbank の公開 API に対する、真逆のアプローチ**の姉妹プロジェクトです。

- **MCPサーバ**は、サーバ側で計算済みの分析結果を AI に渡します。つないだ瞬間からテクニカル分析や可視化が「すぐ使える」代わりに、分析の中身はツール側にお任せです
- **CLI** は、生データを AI に渡して、計算や分析ロジックは LLM（とあなた）に任せます。指標のパラメータもロジックも自由に設計できる代わりに、組み立てはあなた次第です

| | MCPサーバ | CLI |
|---|---|---|
| おすすめの方 | トレード初〜中級者 | トレード中〜上級者・開発者 |
| 分析の仕方 | サーバ側で計算済みの結果を返す | 生データを渡し、計算は LLM / 自分で設計 |
| 得意なこと | すぐ使える指標分析・可視化・取引実行 | 指標パラメータやロジックの完全カスタマイズ |
| 推奨クライアント | Claude Desktop | Claude Code / Cursor / Codex |

**迷ったら MCP から**。分析を自分の手で組みたくなったら CLI、と覚えてください。詳しい使い分けはドキュメントサイト「[bitbank-lab-docs](https://bitbank-lab.gitbook.io/bitbank-lab-docs)」にもまとめています。

## 3. bitbank-lab-mcp を 5 分で試す

インストール作業はありません。`npx` 経由で起動するため、**Claude Desktop の設定ファイルに数行追記するだけ**で完了します。

**前提**: Node.js 22 以上（`node -v` で確認）／ [Claude Desktop](https://claude.com/ja/download)

### 3-1. 設定ファイルに追記する

`claude_desktop_config.json` を開きます。

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

追記する内容は、**用途に応じて A / B / C の 3 段階**から選べます。あとから `env` を足すだけで昇格できるので、まずは A で大丈夫です。

**A. Public データのみ（API キー不要）**

価格・板・ローソク足などの公開市場データの取得と分析ができます。

```json
{
  "mcpServers": {
    "bitbank-lab": {
      "command": "npx",
      "args": ["-y", "bitbank-lab-mcp"]
    }
  }
}
```

**B. Private データ参照系（要 API キー）**

A に加えて、資産残高・約定履歴・ポートフォリオ分析などの**読み取り専用**機能が使えます。発注はできません。

```json
{
  "mcpServers": {
    "bitbank-lab": {
      "command": "npx",
      "args": ["-y", "bitbank-lab-mcp"],
      "env": {
        "BITBANK_API_KEY": "your_api_key",
        "BITBANK_API_SECRET": "your_api_secret"
      }
    }
  }
}
```

> ✅ bitbank API キーの権限は**「参照」のみ**の設定を推奨します。

**C. 取引注文・注文キャンセル実行（要 API キー）**

B に加えて、AI からの発注・注文キャンセルまで実行できます。実行前には必ず確認ステップが入ります。

```json
{
  "mcpServers": {
    "bitbank-lab": {
      "command": "npx",
      "args": ["-y", "bitbank-lab-mcp"],
      "env": {
        "BITBANK_API_KEY": "your_api_key",
        "BITBANK_API_SECRET": "your_api_secret",
        "BITBANK_TRUST_HOST_APPROVAL": "1"
      }
    }
  }
}
```

> ✅ bitbank API キーの権限は**「参照」および「取引」のみ**の設定を推奨します。
> ⚠️ **「出金」権限は有効化しないでください**。本サーバは出金系ツールを実装していないため、不要です。

見比べるとわかるとおり、A → B → C の差分は `env` ブロックだけです。この 3 段階は、**「AI に渡す権限を、自分のペースで段階的に広げていくはしご」**として設計しています。まず公開データで遊び、信頼できたら参照キーを渡し、取引まで任せるかは最後に自分で決める — という流れです（この設計思想は後半の「[安全性への考え方](#5-安全性への考え方--aiエージェント前提のガードレール)」で詳しく触れます）。

### 3-2. 再起動して、話しかける

Claude Desktop を**完全終了して再起動**したら、新規チャットで話しかけてみてください。

> BTC/JPY の今の価格を教えて

リアルタイム価格が返ってくれば成功です。続けて、こんなことも聞けます。

> BTC の今の市場状況を分析して
>
> ビットコインは買いと売りどちらが優勢？
>
> ここ 30 日のボラ推移をチャートで見せて

> 🖼 **ここにスクリーンショットを挿入**（1〜2枚）: 市場分析の会話／SVG チャートが表示された画面

うまく動かない場合や、Cursor・Claude Code など他のクライアントで使いたい場合は、[ドキュメントのセットアップガイド](https://bitbank-lab.gitbook.io/bitbank-lab-docs)を参照してください。

### 3-3. MCP のユースケース例

**☀️ 朝のキャッチアップ** — 「おはようレポートを出して」と話しかけると、寝ている間の相場変動をまとめて要約してくれます。朝のルーティンにどうぞ。

**📊 ポートフォリオ分析** — 冒頭の動画の種明かしです。B の設定（読み取り専用キー）を入れると、「ポートフォリオの状況を見せて」で資産構成や損益を会話で確認できます。

**📝 自然言語で注文・キャンセルまで** — C の設定では、「BTC を成行で 0.001 買って」のような依頼から発注までつながります。ただし AI が勝手に約定させることはできません。**必ず注文内容のプレビュー → 確認 → 実行の 2 ステップ**を踏み、最後の確認はあなたの手に残ります。

> 🖼 **ここにスクリーンショットを挿入**: 注文プレビュー → 確認ダイアログの画面（「勝手に約定しない」ことが伝わる画）

**💡 何を聞けばいいか迷ったら — Prompts 機能** — Claude Desktop のプロンプトメニューに、初心者🔰向けから中級者向けまでの分析プロンプトが組み込みで表示されます。選ぶだけで分析が始まるので、最初の一歩はここからでも。一覧は[プロンプト集](https://github.com/bitbankinc/bitbank-lab-mcp/blob/main/docs/prompts-table.md)にもまとめています。

> 🖼 **ここにスクリーンショットを挿入**: Claude Desktop の Prompts メニュー

## 4. bitbank-lab-cli を 5 分で試す

**前提**: Node.js 22 以上

### 4-1. まずはターミナルで動作確認

```bash
npm i -g bitbank-lab-cli

bitbank ticker btc_jpy
bitbank candles btc_jpy --type=1day --format=table
```

インストールせずに試すなら `npx -y bitbank-lab-cli ticker btc_jpy` でも動きます。

### 4-2. コーディングエージェントにつなぐ

CLI の本命は、**Claude Code などのコーディングエージェントから自然言語で使う**体験です。Claude Code なら、slash command を 1 行ずつ実行するだけで、CLI の使い方を知っている **Agent Skills（12 本）** がまとめて入ります。

```text
/plugin marketplace add bitbankinc/bitbank-lab-cli
```

```text
/plugin install bitbank-lab-cli@bitbank-lab-cli
```

あとは話しかけるだけです。Skill が必要なコマンドを組み立てて、データ取得から分析まで実行してくれます。

> BTC の RSI を見て
>
> SMA クロス戦略をバックテストして
>
> 買う前にざっと見て

> 🖼 **ここにスクリーンショット（or 会話ログ）を挿入**（1〜2枚）: Claude Code で Skill が発火し、コマンドを組み立てて分析結果を返す様子

Cursor / Codex / Antigravity CLI での導入手順は [README](https://github.com/bitbankinc/bitbank-lab-cli#plugin-としてインストールする) を参照してください。

### 4-3. CLI のユースケース例

**🔧 自由度の高い分析** — CLI は生データを AI に渡す設計なので、「RSI を 20 期間で計算して」「この 2 銘柄のラグ相関を見て」のような細かい注文が通ります。指標のパラメータも、分析ロジックそのものも、あなたと AI の側で自由に設計できます。`--format=csv` でローソク足を書き出して、手元の分析環境に持ち込むのも簡単です。

```bash
bitbank candles btc_jpy --type=1day --format=csv > btc_daily.csv
```

**🧩 サンプル Skill で遊ぶ・育てる** — plugin として入る Skill は、テクニカル指標・相関分析・ボラティリティ分析・バックテストなどの分析系 7 本に加え、複数の Skill を束ねる「レシピ」も同梱しています。たとえば「買う前にざっと見て」で起動する `recipe-pre-trade-check` は、保有資産 → ボラ環境 → データ品質 → テクニカルを順に確認して **GO / WAIT / NO-GO** の総合判断まで出します（最終判断はあなたです）。
そして Skill は**自分で追加・編集して育てる前提**です。`skills/<name>/SKILL.md` を 1 枚置くだけで、あなた専用の分析ワークフローを AI に教えられます。ここが CLI の一番面白いところだと思っています。

**🎮 ペーパートレードで AI 売買の練習** — 「BTC を仮想で 0.01 買って」と頼むと、**ライブ価格 × 仮想資金**のペーパートレードができます。実際の API は公開データしか使わないので、資金もキーも不要。損益確認・指値・リセットまで一通り揃っているので、取引系の機能を試す前の練習場としておすすめです。

> 🖼 **ここにスクリーンショット（or 会話ログ）を挿入**: ペーパートレードの売買〜損益確認の様子

## 5. 安全性への考え方 — AIエージェント前提のガードレール

今回のツールは、**操作者が人間ではなく AI エージェントになる**ことを前提に、ガードレールをしっかり目に作っています。

操作者が AI になると、指示の誤解釈やプロンプトの誤コピーから「意図しない発注」が起きる可能性を考えなくてはなりません。そこで、**お金が動く操作には、AI が会話の勢いでは通せない形の確認**を必ず挟んでいます。

- **MCPサーバ**: 発注・キャンセルは preview → execute の 2 ステップ + ホスト側の承認ダイアログを必ず経由します。取引ツールの承認は「常に許可（Always allow）」にせず、毎回内容を確認する運用を推奨しています
- **CLI**: 取引コマンドはデフォルトが**ドライラン**（API を叩きません）。実行には `--execute` に加えて、コマンドごとの固定フレーズ `--confirm=I-UNDERSTAND-...` が揃う必要がある二段ロックです

さらに、**出金機能はそもそも実装していません**。出金権限を API キーに付ける理由自体をなくす、という引き算の設計です。

そして、どちらのツールもローカル環境で動作し、API キーの発行・管理は利用者ご自身の手にあります。MCP の A → B → C の 3 段階が示すとおり、**「AI にどこまでの権限を渡すか」は、いつでもあなたが選べます**。まずは「参照」のみの最小権限から始めてください。

とはいえ、これらの安全対策は誤操作を防ぐための**補助機能**であり、完全な防止を保証するものではありません。本ツールはベータ版です。利用は自己責任で、末尾の[免責事項](#免責事項)をご確認のうえお使いください。

## 6. 今後の展開

当社は今後のプロダクト化を見据え、AI エージェントが取引所のデータや機能を扱うことで生まれる価値と課題を、実際の利用とフィードバックを通じて段階的に検証していきます。

- まずは今回のローカル版で、AI がマーケットデータや資産情報を**安全に扱えるか**を検証します
- 並行して、**リモート MCP サーバ**での提供も視野に、まずはパブリックデータの連携から段階的に構築を進めます。その後、プライベートデータや取引機能との連携、チャット上の動的な UI を通じた確認・操作体験などへの拡張を見据えています
- 将来的には、利用者が設定した方針・条件・リスク許容度に基づき、AI エージェントがマーケット分析からポートフォリオ管理、注文操作までをより自律的に担う、新しい取引体験の実現を目指します
